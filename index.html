数据说明
  • 数据仅来自本机 ~/.local/share/mimocode/mimocode.db，解析 assistant 消息中的 tokens 字段；统计过程不调用小米 API。
  • 在线时每 15 秒自动刷新一次（页面切到后台会暂停轮询）；也可点击「在线」手动暂停，或按 R 立即刷新。
  • mimo-auto 可能是桌面端 Smart入口：多数记录里统计的是该入口 ID，而不是路由后的具体模型。若服务端回写了实际模型，则以该 modelID 计入。
  • 模型 ID 可能随客户端版本变化。本机现行包中常见 mimo-flash / mimo-pro；历史数据中仍可见 mimo-x-flash-preview / mimo-x-pro-preview，新旧 ID 会并列出现。
  • 总消耗 = input + output + reasoning + cache.read + cache.write（存在 tokens.total 时优先使用）。
