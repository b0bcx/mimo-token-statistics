数据说明

统计口径与来源

  • 数据仅来自本机 ~/.local/share/mimocode/mimocode.db，解析 assistant 消息中的 tokens 字段；统计过程不调用小米 API。
  • 在线时按设定间隔自动刷新（默认 15 秒，可在设置中调整；页面切到后台会暂停）；也可点「在线」暂停，或按 R 立即刷新。
  • mimo-flash / mimo-pro：桌面端 Smart 入口自动路由后的具体模型；mimo-x-flash-preview / mimo-x-pro-preview：未走 Smart 路由的常规 flash / pro；mimo-auto：旧版 mimocode CLI 的模型 ID。
  • 不同入口的模型 ID 会按数据源原样并列展示，不自动合并。
  • 总消耗 = input + output + reasoning + cache.read + cache.write（存在 tokens.total 时优先使用）。
